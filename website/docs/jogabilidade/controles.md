# Controles

## Durante a partida

| Tecla | Ação |
|---|---|
| <kbd>W</kbd> ou <kbd>↑</kbd> | Mover para cima |
| <kbd>A</kbd> ou <kbd>←</kbd> | Mover para a esquerda |
| <kbd>S</kbd> ou <kbd>↓</kbd> | Mover para baixo |
| <kbd>D</kbd> ou <kbd>→</kbd> | Mover para a direita |
| <kbd>Espaço</kbd> | Atirar |
| <kbd>M</kbd> | Ligar ou desligar o som |
| <kbd>R</kbd> | Jogar novamente (só após o fim da partida) |
| <kbd>Esc</kbd> | Sair do jogo |

A nave se move 12 pixels por quadro e não consegue sair da janela: os limites da tela são aplicados nos quatro lados.

## No login

| Tecla | Ação |
|---|---|
| Letras, números, `_` e `-` | Digitar o nome (máximo de 16 caracteres) |
| <kbd>Backspace</kbd> | Apagar o último caractere |
| <kbd>Enter</kbd> | Confirmar (o nome não pode ser vazio) |

## No menu

O menu é controlado com o **mouse**: clique em **JOGAR**, **RANKING** ou **SAIR**. Aqui <kbd>M</kbd> também liga e desliga o som. Na tela de ranking, <kbd>Esc</kbd> ou o botão **VOLTAR** retorna ao menu.
