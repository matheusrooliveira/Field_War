# Tecnologias e processo

## Tecnologias

| Tecnologia | Finalidade |
|---|---|
| Python 3.12 | Linguagem principal |
| Pygame CE (`pygame-ce>=2.5.8`) | Gráficos, eventos, colisões e áudio |
| SQLite (`sqlite3`) | Persistência de jogadores e recordes |
| NumPy | Apenas no script `tools/gerar_audio.py` (síntese dos sons) |
| PlantUML | Diagramas de classe, herança e sequência |
| Docusaurus | Esta documentação |
| Git e GitHub | Controle de versão e colaboração |
| Jira | Gestão ágil: planejamento e sprints |

## Conceitos de engenharia de software aplicados

- Programação orientada a objetos
- Arquitetura modular (pasta `sistemas/` separada das entidades)
- Algoritmos e lógica de programação
- Detecção de colisão e tratamento de eventos
- Gerenciamento de estados de jogo
- Integração com banco de dados e persistência de dados
- Versionamento e desenvolvimento colaborativo
- Metodologias ágeis (Scrum)

## Equipe

O Field War é um projeto acadêmico desenvolvido em grupo no curso de Ciência da Computação. O código fica no GitHub e as tarefas são organizadas no Jira.
